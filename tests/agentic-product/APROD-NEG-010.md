# APROD-NEG-010 ; Product containing an Agent automatically becomes Agentic Product

Per CR-ES-016 §24.10 and ADR-ES-016 §6.

## Test Assertion

Product containing an Agent automatically becomes Agentic Product per CR-ES-016 §24.10.

## Verdict

PASS ; if the validator recognizes the assertion in conformance mode.

FAIL ; if the validator does not recognize the assertion.

## Validator Behavior

Per CR-ES-016 §25 + §26, the CI validator must explicitly recognize this conformance pattern.
